## Selected work

**[leashd](https://github.com/brainbytes-dev/leashd):** Non-custodial spend governance for autonomous AI agents. Budget caps, scoped credentials, kill-switch, signed audit trail. Lightning + stablecoins, MCP-native.

**[nextjs-expo-saas-starter](https://github.com/brainbytes-dev/nextjs-expo-saas-starter):** Ship web + mobile SaaS in days. Next.js 16 · Expo SDK 55 · Stripe · RevenueCat · Better-Auth · Drizzle · Turborepo. Fully wired, zero boilerplate.

**[everything-claude-trading](https://github.com/brainbytes-dev/everything-claude-trading):** A complete trading and quantitative-finance system for Claude Code. Agents, skills, commands.

**[everything-claude-finance](https://github.com/brainbytes-dev/everything-claude-finance):** Finance, accounting and economics for Claude Code, in one installable system.

**[everything-claude-marketing](https://github.com/brainbytes-dev/everything-claude-marketing):** Marketing intelligence for Claude Code, covering every discipline end to end.

**[engpassradar](https://github.com/brainbytes-dev/engpassradar):** Swiss drug-shortage tracker. Scrapes the official register daily, surfaces shortages with search, filters and detail views.
